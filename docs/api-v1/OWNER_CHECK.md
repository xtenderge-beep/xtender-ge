# Проверка сделки владельцем: ChatGPT, SMS, сайт

Локальные тесты проходят, но настоящий ChatGPT, настоящие SMS и телефон проверяет только владелец. Это проверка в
**тестовом окружении** (отдельный адрес, своя база, рассылки выключены), не на xtender.ge. Около 40 минут.

## Подготовка (один раз)

1. **Разрешите** отправить ветку `api-v1-stage1` на GitHub (не `main` — `main` выкладывает сайт).
2. **Railway**: пустое окружение `staging` по шагам [BACKEND_AUDIT.md](BACKEND_AUDIT.md), раздел 13, и ещё переменные:

   | Переменная | Значение |
   |---|---|
   | `SANDBOX_REAL_SMS_NUMBERS` | Ваш номер (+995…) |
   | `SANDBOX_REAL_DEAL_SMS` | `1` — SMS о предложениях придут на ваш номер по-настоящему |
   | `SANDBOX_SEED` | `1` — появятся тестовые исполнители (номера выдуманные) |
   | `SANDBOX_SINK_KEY` | Длинная случайная строка — ключ к списку «отправленных» SMS тестовых номеров |
   | `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` | **Новые**, не как на рабочем сайте — вход модератора в тестовую админку |

3. **ChatGPT**: настройки → режим разработчика → новое приложение с адресом `https://<адрес>/mcp`, вход OAuth.

## Проверка

Пишите ChatGPT обычными словами. Если ответ не такой, как в «ожидаем», — снимок экрана и номер шага.

1. **Вход.** «Покажи мой аккаунт xtender». ChatGPT предложит подключить → страница xtender → ваш номер → код из SMS →
   «Разрешить». Ожидаем: номер без середины.
2. **Заявка.** «Нужны два грузчика в Тбилиси, Ваке, занести диван на третий этаж без лифта, послезавтра в 10:00».
   ChatGPT уточнит, покажет итоговую заявку и спросит подтверждение — подтвердите. В первый раз он даст ссылку на
   страницу согласия: откройте, отметьте две галочки и галочку SMS, «Подтвердить», вернитесь и скажите «публикуй».
   Ожидаем: «заявка передана на проверку», SMS со ссылкой на страницу заявки.
3. **Модерация.** `https://<адрес>/admin` → «Заявки» → ваша заявка → разослать «Грузчики». Ожидаем: 2 получателя
   (SANDBOX Movers Giorgi и SANDBOX Movers Dato).
4. **Ответ первого исполнителя.** Откройте `https://<адрес>/api/v1/sandbox/sms?key=<ключ>&phone=%2B995500000002`, там
   SMS с заявкой — откройте ссылку. Страница попросит войти: номер `+995500000002`, код — по той же ссылке на список SMS.
   На заявке задайте вопрос и отправьте предложение 150 ₾. Ожидаем: на ваш телефон одна SMS «got its first offer» со
   ссылкой (с 22:00 до 09:00 она ждёт утра).
5. **Ответ второго.** То же для `+995500000005` (в ссылке `%2B995500000005`): 120 ₾ и «дополнительные расходы» без
   суммы. Ожидаем: второй SMS о первом предложении нет.
6. **Ссылка из SMS.** Откройте её на телефоне. Ожидаем: номер заявки, «Предложений: 2», цен и телефонов нет, кнопки
   «Скопировать» и «Открыть ChatGPT».
7. **Сравнение в новом чате.** Нажмите «Открыть ChatGPT» (или вставьте текст). Ожидаем: ChatGPT находит заявку, видит
   вопрос исполнителя, сравнивает: у второго итог **неизвестен** (не 120 ₾ и не ноль).
8. **Ответ и выбор.** «Ответь исполнителю: диван проходит в дверь», затем «выбираю предложение Giorgi». ChatGPT спросит
   подтверждение — да. Ожидаем: «ждём подтверждения исполнителя».
9. **Подтверждение.** Как в шаге 4, войдите `+995500000002`, откройте заявку → «Подтверждаю — беру заказ». Ожидаем:
   в ChatGPT («покажи заявку») и на странице заявки по ссылке из SMS шага 2 — телефон исполнителя; у исполнителя —
   ваш телефон и адрес.
10. **Без ChatGPT.** На странице заявки (ссылка из SMS шага 2) — «Работа выполнена — завершить заявку». Посмотрите
    страницу на трёх языках флажками.

После проверки окружение можно удалить: на рабочий сайт оно не влияет.
