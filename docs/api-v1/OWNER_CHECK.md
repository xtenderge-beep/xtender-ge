# Проверка владельцем: тестовое окружение, ChatGPT, SMS

Локальные тесты проходят (pg-mem и PostgreSQL 18.4), но настоящий ChatGPT, настоящие SMS и телефон проверяет только
владелец. Всё — в **тестовом окружении** (свой адрес, своя база, рассылки выключены), не на xtender.ge. Около 45 минут.
Интеграция с ChatGPT не считается проверенной, пока эти шаги не пройдены.

## Что нужно от вас заранее

1. **Разрешение отправить ветку `api-v1-stage1` на GitHub** (не `main`: `main` выкладывает сайт). Репозиторий открытый —
   код ветки станет виден; паролей и ключей в нём нет.
2. **Railway — пустое окружение** `staging` в проекте `fabulous-luck` (шаги — [BACKEND_AUDIT.md](BACKEND_AUDIT.md), раздел 13):
   «+ New Environment» → **Empty Environment** (не Duplicate: копия перенесла бы ключ Telegram-бота и ключи шлюза), в нём
   PostgreSQL, Redis и приложение из репозитория с веткой `api-v1-stage1`, Networking → «Generate Domain».
   **Платно**: окружение расходует ресурсы вашего тарифа Railway как небольшая копия сайта; сумму видно в Usage. После
   проверки окружение удаляется и на рабочий сайт не влияет.
3. **Переменные приложения — до первого запуска:**

   | Переменная | Значение |
   |---|---|
   | `DATABASE_URL`, `REDIS_URL` | PostgreSQL и Redis **этого** окружения |
   | `XTENDER_SANDBOX` | `1` |
   | `DOMAIN` | Адрес из «Generate Domain», без `https://` |
   | `NODE_ENV` | `production` |
   | `SMS_GATEWAY_USERNAME`, `SMS_GATEWAY_PASSWORD` | Как на рабочем сайте; вписываете сами, в чат не присылаете |
   | `SANDBOX_REAL_SMS_NUMBERS` | Ваш номер (+995…) |
   | `SANDBOX_REAL_DEAL_SMS` | `1` — SMS о предложениях придут на ваш номер по-настоящему |
   | `SANDBOX_SEED` | `1` — тестовые исполнители (номера выдуманные, коды входа — в приёмнике) |
   | `SANDBOX_SINK_KEY` | Длинная случайная строка — ключ к списку SMS тестовых номеров |
   | `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` | **Новые**, не как на рабочем сайте — тестовая админка |
   | Не задавать | `TELEGRAM_*`, `OPENROUTER_API_KEY`, `GA_MEASUREMENT_ID`, `META_PIXEL_ID`, `ADMIN_PHONE` |

4. **Пришлите мне адрес окружения** (ключ приёмника — по желанию). Я запущу проверку одной командой
   `node scripts/staging-check.js https://<адрес> [ключ]`: песочница включена, вход OAuth совпадает с требованиями ChatGPT,
   инструменты на месте, тестовые исполнители есть, приёмник закрыт. Без «PASS» по всем пунктам ChatGPT не подключаем.
5. **ChatGPT**: нужен аккаунт, где есть «Add custom MCP server». Официальная страница OpenAI («Connect and test your
   plugin», developers.openai.com/plugins/deploy/connect-chatgpt, сверено 2026-10-24) тарифы не называет; по сторонним
   описаниям действия, которые меняют данные, доступны не на всех тарифах. Проверьте в своём аккаунте; ChatGPT перед
   такими действиями спрашивает подтверждение сам.

## Подключение ChatGPT (по официальной странице OpenAI)

1. Откройте chatgpt.com/plugins → кнопка «+» → **Add custom MCP server**.
2. Имя: `Xtender (test)`, описание любое. В **Connection** — адрес `https://<адрес>/mcp`.
3. Вход — OAuth (ChatGPT сам зарегистрируется у нас). Прочитайте предупреждение → **I understand and want to continue** →
   **Create as a plugin**. Должен появиться список инструментов (около 39).
4. Новый чат → в поле ввода «@» → выберите `Xtender (test)`.

Если ChatGPT показывает ошибку входа — снимок экрана и время, я найду запись в журнале сервера.

## Проверка

Пишите обычными словами. Не совпало с «ожидаем» — снимок экрана и номер шага.

1. **Вход.** «Покажи мой аккаунт xtender» → подключить → страница xtender → ваш номер → код из SMS → «Разрешить».
   Ожидаем: номер без середины.
2. **Заявка.** «Нужны два грузчика в Тбилиси, Ваке, занести диван на третий этаж без лифта, послезавтра в 10:00».
   ChatGPT уточнит, покажет заявку, скажет, сколько исполнителей подходит сейчас (это не обещание ответа), и спросит
   подтверждение — подтвердите. В первый раз — ссылка на страницу согласия: две галочки и галочка SMS, «Подтвердить»,
   вернитесь и скажите «публикуй». Ожидаем: «заявка передана на проверку», SMS со ссылкой на страницу заявки.
3. **Модерация.** `https://<адрес>/admin` → «Заявки» → ваша заявка. Над формой — «Требования подготовлены из параметров
   заказчика»; если ChatGPT передал число грузчиков, бригада «от 2» уже стоит. Отправьте. Ожидаем: 2 получателя (SANDBOX
   Movers Giorgi и Dato). Если поменяете требование вручную — оно появится в журнале внизу карточки заявки.
4. **Ответ первого исполнителя.** `https://<адрес>/api/v1/sandbox/sms?key=<ключ>&phone=%2B995500000002` — SMS с заявкой,
   откройте ссылку, войдите номером `+995500000002` (код — по той же ссылке). Задайте вопрос и отправьте предложение
   150 ₾. Ожидаем: на ваш телефон одна SMS «got its first offer» со ссылкой (с 22:00 до 09:00 она ждёт утра).
5. **Второй исполнитель.** То же для `+995500000005`: 120 ₾ и «дополнительные расходы» без суммы. Второй SMS нет.
6. **Ссылка из SMS** на телефоне: номер заявки, «Предложений: 2», без цен и телефонов, «Открыть ChatGPT».
7. **Сравнение в новом чате** (кнопка «Открыть ChatGPT» или вставить текст): у второго итог **неизвестен**, а не 120 ₾.
8. **Ответ и выбор.** «Ответь исполнителю: диван проходит в дверь», затем «выбираю предложение Giorgi» → да.
9. **Подтверждение.** Войдите `+995500000002`, откройте заявку → «Подтверждаю — беру заказ». Ожидаем: в ChatGPT и на
   странице заявки — телефон исполнителя, у исполнителя — ваш телефон и адрес.
10. **Без ChatGPT.** На странице заявки — «Работа выполнена». Посмотрите её на трёх языках флажками.
11. **18 тонн.** «Нужно перевезти 18 тонн стройматериалов из Тбилиси в Рустави» — черновик, не публикуйте. Ожидаем:
    подходящих машин 0 — у SANDBOX Van Levan грузоподъёмность не указана, а неизвестная не считается подходящей. В
    админке → «Специалисты» → SANDBOX Van Levan → у машины «Грузоподъёмность, т» = 20 → сохранить. Попросите ChatGPT
    проверить черновик ещё раз: подходит 1.
12. **Новая категория без правки плагина.** В админке → «Категории» → новая «Клининг» с характеристикой «Уборка после
    ремонта» (да/нет, «Требуется отметка») и словами поиска «уборка, клининг, dalageba»; затем в её параметрах заявки —
    «Площадь, м²» и «После ремонта» со сравнением с характеристикой. В ChatGPT: «нужна уборка квартиры после ремонта».
    Ожидаем: ChatGPT находит «Клининг» и спрашивает площадь.

После проверки окружение можно удалить: на рабочий сайт оно не влияет.
