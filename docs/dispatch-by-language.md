# Рассылка заявки по языку исполнителя

Модератор выбирает, кому отправить заявку: всем исполнителям группы (как было всегда) или
только тем, кто отметил нужный язык при регистрации. Зачем: платный лид, который исполнитель
не может обслужить из-за языка, — прямой повод для жалобы, а заказчик остаётся без ответа.

Решение владельца (2026-09-21): по умолчанию заявка по-прежнему уходит всем, язык — второй
шаг после выбора категории, с кнопкой «Все».

---

## 1. Как пользоваться

**Telegram.** Нажатие на категорию больше не рассылает сразу, а открывает выбор в том же
сообщении:

- «Все (N)» — как раньше;
- «Говорят по-русски / по-грузински / по-английски (N)» — только отметившие этот язык;
- «Язык не указан: N» — справка: эти исполнители получат заявку только при «Все»;
- «← К категориям» — назад.

N — сколько исполнителей получат заявку сейчас: с достаточным балансом и согласием на
тарифы, без уже получивших эту заявку. Уже отправленный вариант помечен «✅ … · отправлено».
После рассылки сообщение возвращается к списку категорий и показывает строку
«Грузчики · говорят по-русски — N». В Telegram три языка; исполнители, говорящие только на
армянском, азербайджанском, турецком или украинском, доступны через «Все» или админку.

**Админка.** В форме «Отправить заявку исполнителям» (`/admin/orders/<token>`) появился выбор
адресата. В предпросмотре (`/admin/orders/<token>/dispatch`) видно, кому идёт рассылка, числа по
каждому языку со ссылками для переключения и сколько исполнителей уже получили заявку.

## 2. Правила

1. **Язык — только то, что исполнитель отметил** (`masters.spoken_languages`). Язык кабинета
   (`masters.language`) не в счёт: у аккаунтов, созданных до его появления, он равен значению по
   умолчанию `ka`.
2. **Без указанных языков — в языковую рассылку не входят.** Их число всегда видно рядом
   («Язык не указан»); получают только при «Все». Причина: смысл выбора — исключить тех, кто не
   поймёт клиента. У аккаунтов, созданных до поля «языки общения», список пуст.
3. **Язык входит в ключ рассылки.** Заявку можно отправить по-русски, а позже всем:
   получившие второй раз не платят и не входят в число получателей (`dispatch.service.preview`
   исключает тех, у кого уже есть списание `lead_charge` по этой заявке; `notifyMasters` дополнительно
   проверяет это под блокировкой). Тот же язык и та же группа второй раз не отправляются.
4. **«Упущенный лид» из-за баланса** засчитывается только тем, кто говорит на языке рассылки, и не
   больше одного раза за заявку и группу (`notifyMasters`, блок `broke`).
5. **Кнопки из старых сообщений** (созданных до выбора языка) приходят без языка и рассылают
   всем, как раньше. «🔄 Обновить категории» заменяет их новыми.
6. Закрытая категория по-прежнему не рассылается ни на каком языке.

## 3. Где в коде

| Что | Где |
|---|---|
| Разбор адресата, «говорит ли», счётчики по языкам | `src/config/spokenLanguages.js` |
| Предпросмотр, отправка, причина пустой выборки | `src/services/dispatch.service.js` |
| Отбор получателей, запись рассылки, «упущенные» лиды, история | `src/services/order.service.js` (`getDispatchRecipients`, `recordDispatch`, `notifyMasters`, `getOrderDispatches`) |
| Кнопки и выбор адресата | `src/services/telegram.service.js` (`buildLanguageKeyboard`, `showLanguagePicker`) |
| Нажатия `pick:`, `cat:…:<язык>`, `pick_head:`, `lang_info:` | `src/controllers/order.controller.js` (`telegramWebhook`) |
| Форма и предпросмотр | `src/views/admin/order-detail.ejs`, `src/views/admin/dispatch.ejs` |

Формат кнопки рассылки: `cat:<token>:<группа>:<размер>:<версия заявки>:<язык>`, язык `all` —
всем. Категория теперь открывает выбор кнопкой `pick:<token>:<группа>:<размер>:<версия>`.
Лимит Telegram на `callback_data` — 64 байта; тесты это проверяют.

## 4. База данных

- `order_dispatches.language VARCHAR(5) NOT NULL DEFAULT ''` — пусто значит «всем».
- Уникальность теперь по `(order_id, category, vehicle_size, language)` — уникальный индекс
  `uq_order_dispatches_group`. Прежний ключ без языка снимается в `schema.sql` по имени
  `order_dispatches_order_id_category_vehicle_size_key` (в `CREATE TABLE` оно задано явно, чтобы
  pg-mem его находил), а на боевой базе запасной вариант по составу колонок лежит в
  `schema.postgres.sql`. Новый индекс создаётся до снятия старого ключа.
- Схема применяется при каждом старте. Ошибка миграции не даёт сайту подняться, поэтому после
  выкладки нужна проверка на проде — см. задачу в [tasks.md](tasks.md).

## 5. Не сделано

- Автоматическая рассылка «сначала владеющим языком, потом всем через N минут» — только вручную.
- Правка языков исполнителя в админке: у старых аккаунтов их можно задать только повторной
  регистрацией.
- Объявления исполнителям по языкам (не заявки): на них нет согласия. Оферта п. 1.4.4 исключает
  маркетинговые рассылки, а галочка при регистрации покрывает только сервисные уведомления.

Тест: `node tests/dispatch-language.test.js` (предпросмотр, списания, повторная отправка,
«упущенные» лиды, кнопки и вебхук Telegram, страницы админки).
