# Компании для обзвона (`/admin/outreach/prospects`)

Владелец сам звонит компаниям, которые нашёл в поиске (например, топ-20 Google по «ავეჯის გადაზიდვა» и «ნაგვის გატანა»),
и подключает тех, кто согласился, через обычную анкету от бота ([outreach-bot-drafts.md](outreach-bot-drafts.md)).

## Как работает

1. **Список.** Загружается по API с тем же ключом, что у бота (Рассылки → Анкеты от бота → Выпустить ключ):
   `POST /api/outreach/prospects` с `{ "source": "google_top20", "prospects": [ {…}, … ] }` (до 500 за раз).
   Поля компании: `name` (обязательно), `phone` или `phones` (первый грузинский номер — основной), `website`,
   `email`, `title`, `description`, `services` (коды сайта; `transport` → `van`; неизвестный код уходит в
   `other_services`), `other_services`, `found_where`, `note`. Нужен номер или сайт. Повтор с тем же номером или
   сайтом обновляет карточку и не трогает итоги звонков. Ответ: `{ created, updated, skipped: [{ index, reason }] }`.
2. **Список в админке.** Только администратор: на сайте компаний нет, сайт им ничего не отправляет. Фильтры по
   стадии, услуге, поиску.
3. **Карточка.** Номер (кнопка «позвонить»), сайт, услуги, где нашли, заметка, журнал звонков. Итог звонка:
   не дозвонился, перезвонить, отказался, просил не звонить, заметка. «Просил не звонить» вносит номер в общий
   список отказа (`outreach_optouts`, источник `admin`, событие `OUTREACH_OPT_OUT` с `actor: admin`).
4. **Согласился.** Владелец ставит отметку «компания согласилась по телефону» и создаёт ссылку: это обычный
   черновик анкеты (`provider_drafts`, источник `owner_call`, `external_id = prospect_<id>`), описание — без номеров.
   В журнал согласий пишется `OUTREACH_PHONE_AGREED` (канал `phone`, кто и когда отметил). Это не согласие на SMS:
   галочки (оферта, политика, SMS о заявках, предложения) компания ставит сама на `/c/<token>` и подтверждает
   кодом из SMS сайта — как на `/join`.
5. **Отправка ссылки.** Со своего телефона владельца: в карточке готовый текст на ka и ru и кнопки WhatsApp и
   SMS. Сайт ссылку не отправляет. Ссылка живёт 14 дней.
6. **Стадии** считаются по живому состоянию номера: исполнитель уже есть — «Подтвердил — исполнитель»; открыл
   ссылку; ссылка истекла; «Не интересно» на странице; в списке отказа.
