# Xtender

**xtender.ge** соединяет заказчиков в Грузии с независимыми местными исполнителями — грузчики, перевозки, вывоз мусора
и другие услуги. Рабочий сайт: **https://xtender.ge**

**Вся документация — в папке [docs/](docs/).** Начните с карты [docs/README.md](docs/README.md):

- [docs/project-overview.md](docs/project-overview.md) — проект целиком: идея, гипотезы, принципы, состояние, следующие шаги;
- [docs/technical-overview.md](docs/technical-overview.md) — как устроено внутри, запуск на своём компьютере, проверки, выкладка;
- [docs/tasks.md](docs/tasks.md) — живой список задач.

Правила для сессий разработки — [AGENTS.md](AGENTS.md).
